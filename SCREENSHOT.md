# screenshot.png — manual step

WordPress shows `screenshot.png` (recommended **1200×900**) in **Appearance → Themes**.
It can't be generated without rendering the live site, so add it manually:

1. Activate the theme, open the Home page in a browser at 1200px wide.
2. Capture the top of the page (hero) — or use the design mock `Home-desktop.html`.
3. Save as `screenshot.png` in the theme root (next to `style.css`), 1200×900.

This is cosmetic only — it does not affect the site front end.
